# Word for Markdown v0.1.1

v0.1.1 improves Source mode for long-form Markdown and strengthens local-file reliability.

## 更新内容

- 源码模式支持类似 VS Code 的软换行：长行只在视口内折行显示，不会改写 Markdown，也不会虚增行号。
- 输入、退格、粘贴和选区替换采用更自然的连续撤销分组，并兼容 Windows 中文输入法。
- 缩放、切换视图和标签页后继续保持折行位置，减少长文编辑中的视口跳动。
- 优化大文档的源码变更处理，减少 100 KB 至 1 MB 文档编辑时不必要的整篇复制。
- 修复原子保存后文件监听器可能误报“文件已移动”或外部修改冲突的问题，并覆盖保存回滚路径。

## English

- Source mode now uses VS Code-style soft wrapping. Long lines wrap within the viewport without changing the Markdown or creating extra logical line numbers.
- Typing, backspace, paste, and selection replacement use more natural undo groups, including Windows IME composition.
- Wrapped viewport position is preserved across zoom, view changes, and tab switches.
- Source changes avoid unnecessary whole-document copying for documents from roughly 100 KB to 1 MB.
- Atomic saves no longer trigger false file-moved or external-change conflicts, including rollback paths.

## 安装 / Install

支持 Windows 10/11 x64。安装包提供简体中文与 English，并按当前 Windows 用户安装。

Windows 10/11 x64 is supported. The installer includes Simplified Chinese and English and installs for the current Windows user.

当前公开版本尚未使用商业代码签名证书。若 Windows 显示“未知发布者”，请从本仓库 Releases 下载，并核对发布页提供的 SHA-256。

This public release is not yet signed with a commercial code-signing certificate. If Windows shows an unknown-publisher warning, download from this repository's Releases page and verify the published SHA-256.
